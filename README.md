# 📄 Doc2Form - Open Source AI PDF Converter

An elegant, modern, and high-performance web tool inspired by Doc2Form, built to convert any PDF, Word, or text document into a native Google Form in a matter of seconds. Powered by client-side Google OAuth integration, it features a real-time live preview code workspace and smart user localization.

## 🌟 Key Features

- **⚡ Instant Document Conversion:** Drag and drop your PDFs, Word documents, or text files to simulate a seamless questionnaire extraction.
- **💻 Integrated CodeSpace:** A dual-window HTML editor with an instant Live Preview iframe, allowing you to build and preview form components on the fly.
- **🔐 Secure Google OAuth 2.0 Login:** Authentic, secure client-side login directly utilizing the official Google Identity Services SDK.
- **🌍 Dynamic Account Localization:** Automatically adapts the complete interface language (Polish or English) based on the user's Google Account language preferences (`locale`).
- **🍊 Fresh Orange UI:** Fully responsive, modern, and accessible interface built with Tailwind CSS, customized with dynamic orange accents.

---

## 🛠️ Tech Stack

- **Frontend Architecture:** HTML5, Semantic JavaScript (ES6+)
- **Styling Engine:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Authentication:** [Google Identity Services API](https://developers.google.com/identity/gsi/web)
- **Typography:** Inter Font Family via Google Fonts
